# @nodecraft/commitlint-config
[![CI](https://github.com/nodecraft/commitlint-config/actions/workflows/ci.yml/badge.svg)](https://github.com/nodecraft/commitlint-config/actions/workflows/ci.yml)

Nodecraft's commitlint configuration

## What is commitlint?

commitlint checks if your commit messages meet the conventional commit format.

## Usage

### commitlint.config.js

```js
export default {
	extends: ['@nodecraft/commitlint-config'],
};
```
